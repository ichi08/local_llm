# ノイズ込みのページ全文入力

確認日：2026-10-03。依頼は、短く加工した文章を撤回し、URL先のページ全体の文章をノイズ込みで渡して実運用に近い課題へ変更すること。
本記録は入力の取得・保存・APIへの受け渡しの検証で、LLMの速度や品質の実測ではない。

## 入力の変更

- 入力定義：`benchmarks/google_argon.json`、suite IDは `google-argon-full-page-ja-v2`。
- 対象URL：<https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/>。
- 旧版の短い概要・価格説明・作成した英文を撤回し、8問すべてに同一のページ全文を付ける。
- 要約ではページのノイズと記事を区別する。翻訳2問はメニューからフッターまでの全文翻訳。解説では本文と脚注から必要情報を探す。自由創作でもページ全文を着想源として渡す。
- 入力は `instruction + "\n\n資料：\n" + ページ全文`。モデルにURLへのアクセスは要求しない。

抽出方式は `html-body-text-with-noise-v1`。取得HTMLのbody内の文章を順序どおり保持し、記事部分の選別、言い換え、要約、重複除去、文字数制限は行わない。
メニュー、隠れたメニュー、繰り返す文章、自動要約、関連記事、脚注、著者紹介、フッター、画像のaltを含める。
HTMLタグ・コメント、script・style・templateの内容は文章に含めず、HTMLレイアウト用の空白と改行のみを整理する。
JavaScriptを実行しないため、動的に追加された文章は対象外。画像内の文字のOCRも行わない。

## 実行条件の変更

- 文脈長の既定値：4,096から16,384へ変更。実モデルのメモリや起動成功は未検証。
- 生成数の既定上限：2,048から `-1`（上限なし）へ変更。
- 時間制限：300秒の設定を維持。`--timeout` で変更できる。
- `--no-context-shift` を指定し、生成中に古い入力を捨てる経路を無効にする。
- 文脈長を超える入力は切り詰めずエラーにする。生成が文脈長へ達した場合の打ち切りを、自然に完成した回答の統計へ混ぜない。
- warmupの短い挨拶・16トークンは維持し、計測サンプルへ含めない。
- 4分類各2問×5回、基本280応答の予定数は維持する。

生成数と文脈長の挙動は [検証済みruntime commitの仕様](https://github.com/ggml-org/llama.cpp/blob/7fe450e19/tools/server/README.md) と、[同commitの入力超過チェック](https://github.com/ggml-org/llama.cpp/blob/7fe450e19/tools/server/server-context.cpp) を参照した。
短い旧入力・文脈長4,096・生成上限2,048での過去の結果と、新しい条件の結果は別に扱う。

## 保存と検証

実行ごとに、APIへ送る全文付きプロンプトを埋め込んだ `input-suite.json`、元の定義 `suite-definition.json`、ページのHTML・文章・取得情報を保存する。
`metadata.json` へ元の定義・解決済み入力・ページのSHA-256と保存先を残す。
`--plan` はページを取得せず、保存済み入力の情報、または `input_pending` を表示する。全文を繰り返し端末へ出力しない。

自動テスト38件が成功した。疑似APIで長い入力の末尾まで改変せず送ること、上限なし設定、計測範囲、元キャッシュがなくても保存済み入力を再利用できることを確認した。
HTMLの試験データで、重複メニュー・記事外の文章・ページ末尾の保持、長さによる切り詰めの不存在、ハッシュ不一致の拒否、取得版の更新時に旧版が残ることを確認した。
