## 完了したこと

- 目的とAI向けのルール、セットアップの設計方針を整理した。
- macOS用のPC調査スクリプトと `setup.sh` の入口を実装した。
- M1 Pro / CPU 10コア / GPU 16コア / メモリ16GBの環境を調査した。
- 実機での実行、識別情報の除外、Gitの除外設定を確認した。
- GitHub Publicリポジトリ：<https://github.com/ichi08/local_llm>。
- 2026年の研究を含む一次資料を調べ、create-ruleとプロジェクトの文脈構成を改善した。
- AAのSmall／TinyとHugging Faceの配布元を確認し、基本4モデルと27Bの挑戦枠を選んだ。
- 重みの直接URLをrevision・サイズ・SHA-256付きで定義し、HEADで疎通した。
- 日本語8問、ロード済みAPIの計測、GPU／CPU切替、結果保存を実装した。
- 疑似APIで計測範囲、打ち切り、キャッシュ、GPUフォールバック等を確認した。
- 取得済み重みをプロジェクト・既存キャッシュ・追加の探索先から探し、一致したファイルをその場所から再利用する処理を追加した。
- 4分類各2問の課題案、分類別の採点を性能テストの設計文書へまとめた。
- 利用者の希望を反映し、5回測定を既定とした。各質問の中央値・平均・標本分散・標準偏差・各回の値を保存する。基本280応答、27BのIQ2_Sで40応答を追加する計画。
